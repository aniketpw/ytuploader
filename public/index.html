Step 1 — Create a Google Cloud Project

This is a one-time setup. Takes 30 seconds.

1. Click the button below to open Google Cloud Console
2. Sign in with your Google account (if not already)
3. Click "Select a project" (top bar) → "New Project"
4. Enter any name (e.g. "My YouTube Uploader") → Click "Create"
5. Wait 5 seconds for the project to be created, then select it from the top bar
Open Google Cloud Console ↗

Step 2 — Enable YouTube & Drive APIs

Turn on the APIs your project needs. Click both links below.

1. Click each link below → Click the blue "Enable" button on the page
① Enable YouTube Data API v3 ↗ Required ② Enable Google Drive API ↗ Required

Step 3 — Configure OAuth Consent Screen

Tell Google what your app does. Simple form, 1 minute.

1. Click button below to open OAuth Consent Screen
2. Select "External" → Click "Create"
3. Fill in: App Name (anything) and User Support Email (your email)
4. Scroll to bottom → Add your email in "Developer contact" → Click "Save and Continue"
5. On the Scopes page → Just click "Save and Continue" (skip it)
6. On the Test Users page → Click "Add Users" → Add your own Gmail → Click "Save and Continue"
Open OAuth Consent Screen ↗

Step 4 — Create OAuth Client ID

This generates the key your app needs. Almost done!

1. Click button below to open Credentials page
2. Click "+ Create Credentials" → Choose "OAuth client ID"
3. Application type: "Web application"
4. Under "Authorized JavaScript origins" → Click "+ Add URI" → Paste this exact URL:
http://localhost:3000
5. Click "Create" → A popup will show your Client ID — copy it!
Open Credentials Page ↗

Step 5 — Paste Client ID & Connect! 🎉

You're done! Paste the Client ID you just copied.
